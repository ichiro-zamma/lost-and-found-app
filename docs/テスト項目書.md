# テスト項目書

落とし物管理・マッチングアプリの手動テスト項目書。画面・機能を実装するたびに、該当する項目を埋めて記録する。

## 記入方法

| 列 | 内容 |
|---|---|
| No | 項目番号 |
| 画面/機能 | テスト対象の画面または機能名 |
| 分類 | 正常系 / 異常系 / 境界値 |
| テスト内容 | 何を確認するか |
| 手順 | 実施手順 |
| 期待結果 | 正しく動作した場合に表示・発生するはずの内容 |
| 結果 | OK / NG / 未実施 |
| 備考 | 気づいたことや不具合の詳細 |
